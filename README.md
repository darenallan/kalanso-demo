# Kalanso — captures de la maquette

**Vidéo de démonstration (5 min) :** `video/kalanso-demo-5min.mp4`

Ouvrez **`index.html`** (double-clic, ou le lien GitHub Pages) pour voir toutes les captures d'un coup d'œil ; cliquez sur une image pour l'afficher en grand.

| Dossier | Contenu |
|---|---|
| `1-connexion/` | Choix de l'établissement, connexion, double authentification par SMS, mot de passe oublié, premier accès |
| `2-etudiant/` | Tableau de bord, emploi du temps, notes et simulateur, absences, devoirs, ressources, examens, paiement Orange Money, demandes, campus, messagerie, profil, « Accès refusé » |
| `3-enseignant/` | Tableau de bord, appel (manuel et QR code), saisie des notes, cahier de textes, corrections, ressources, statistiques |
| `4-scolarite/` | Tableau de bord, étudiants (liste, fiche, ajout), formation, emplois du temps et conflits, validation des notes, délibérations, finances (relances SMS, rapprochement), audit, paramètres |
| `5-parent/` | Synthèse, notes, paiements, messagerie |
| `6-mode-sombre/` | Écrans clés en thème sombre |
| `7-mobile/` | Rendu téléphone (390 px) : accueil, notes, planning, paiement, menu, appel, messagerie |
| `8-documents/` | Relevé de notes, convocation, reçu de paiement, PV de délibération, attestation, bibliothèque de composants |

Captures générées automatiquement depuis la maquette (`../kalanso-maquette/index.html`), au format 1440 px de large (390 px pour le mobile). Données fictives.
